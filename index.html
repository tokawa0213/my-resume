概要

細部まで丁寧に取り組むバックエンドエンジニア兼エンジニアリングリードです。楽天グループで、大規模決済プラットフォームの開発・運用に7年以上携わってきました。アーキテクチャ設計からリリース・運用まで、ソフトウェア開発ライフサイクル(SDLC)全体をマネジメントした実績があります。Java/Spring Boot と Azure 上の Kubernetes(AKS)環境を専門とし、高可用性、セキュリティ(PCI DSS)、BCP/DR 戦略に強みがあります。グローバルチーム間の技術連携を推進してきた、日英バイリンガルの人材です。

職務経歴

楽天グループ — Rakuten Pay Online(RPAY)チーム | 2020年4月 – 2026年9月

エンジニアリングリード

2023 – 2026
  • 不正検知システム: Azure Service Bus を用いた非同期データフィードバックと包括的なモニタリングを備えた、リアルタイム不正検知システムを設計・統合しました。
  • 国の税制・規制対応(2023): クレジットカード以外の決済手段の技術的な統合をリードしました。国の税制要件を満たすため、銀行振込サイクルの複雑な改修や新しいルーティングの実装も含みます。
  • グローバル展開: 海外加盟店向けの技術統合をリードしました。要件分析、セキュリティ要件の調整、多通貨対応の請求書フォーマットの開発を担当しました。
  • ワークフロー自動化: Argo Workflows を導入してバッチジョブ管理とジョブネットのオーケストレーションを効率化し、運用効率を大幅に改善しました。
  • セキュリティ・コンプライアンス: PCI DSS 準拠を推進し、コンテンツ改ざんを検知する完全性監視を実装しました。
  • 技術メンタリング: 若手エンジニアを指導し、新技術や外部サービスの更新に関する組織横断のナレッジ共有を進めました。

バックエンドエンジニア

2020 – 2023
  • システム信頼性と BCP: Azure 上の西日本にスタンバイ環境を設計・構築しました。目標復旧時間(RTO)6時間で事業継続性を確保しました。
  • インフラとセキュリティ: 稼働中のシステムで、Azure Application Gateway に Web Application Firewall(WAF)を導入しました。誤検知は最小限に抑えています。
  • パフォーマンス最適化: 社内向けの注文検索アプリケーションを開発し、データベースのインデックスを最適化しました。取引量が増えても性能が劣化しない状態にしています。
  • 運用の卓越性: 運用チームで、監視ダッシュボードの構築、セキュリティ態勢の改善、運用マニュアルの標準化を行いました。運用コストを削減するバッチも開発しました。
  • システム規模: 高トラフィックのプラットフォームを維持しました(API:平均45 QPS/ピーク90 QPS、Web:平均30 QPS/ピーク60 QPS)。
