# my-resume

Tsubasa Okawa Resume

Japanese and English resume, using the Online CV / Orbit theme by Xiaoying Riley and the Jekyll adaptation by sharu725. The required footer attribution is preserved. See LICENSE.md.

## Published site / 公開ページ

- [日本語の履歴書](https://tokawa0213.github.io/my-resume/)
- [English resume](https://tokawa0213.github.io/my-resume/en/)

ページ上部の「日本語 / English」で表示言語を切り替えられます。
Use 日本語 / English at the top of the page to switch languages.

## View CV / 職務経歴書を表示

- [日本語PDF](https://tokawa0213.github.io/my-resume/pdf/ja.pdf)
- [English PDF](https://tokawa0213.github.io/my-resume/pdf/en.pdf)

各言語ページ上部の「職務経歴書を表示 / View CV」ボタンから、対応するPDFを別タブで開けます。
Use View CV at the top of each language page to open the corresponding resume PDF in a new tab.

## Pages

- Japanese: index.html
- English: en/index.html
- Switch language using 日本語 / English in the page header.
- Print / PDF opens the browser's print dialog.

## GitHub Pages

This is a buildless, static site. Relative links support both a user site and a repository project site.

Push this directory to the main branch of the chosen GitHub repository. In Settings → Pages, select GitHub Actions as the publishing source. The included workflow publishes the static Japanese and English pages.
